# Mapa – Sectores de Análisis

🔗 Ver el mapa publicado:
👉 https://mpilarisla.github.io/Mapas-interactivos/sectores_urbanismo1_2025/

Mapa interactivo desarrollado para la cátedra Urbanismo I (FAUD – UNMdP) como herramienta de apoyo al análisis territorial.

El recurso permite visualizar sectores de estudio delimitados para el trabajo práctico y consultar, para cada uno de ellos, información sistematizada a partir del Censo Nacional de Población, Hogares y Viviendas 2022 (INDEC).
